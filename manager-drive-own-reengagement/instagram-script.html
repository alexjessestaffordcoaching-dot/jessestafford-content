I was putting in three or four hours a day and calling it a job. Then I started naming my calendar blocks.

"Focus time" gets eaten by the first request that shows up. "Work on the data report for quality" gets done.

An open block is an invitation. A named block is a decision you already made.

This is the exact pattern I work through with managers. Link in bio if you want to talk it through.
