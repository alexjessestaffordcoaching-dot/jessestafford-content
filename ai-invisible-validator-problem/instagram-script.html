I read a whole contract because I had some extra unallocated moments. A teammate had an AI summary of it instead.

The summary had errors that would have set back our negotiations. Because I read the source, they were not set back. And nobody noticed, because nothing happened.

That is the quiet cost of checking AI's work. A good catch looks exactly like a quiet week.

Your manager only knows what you tell them. Give them one sentence, like: "I found errors in the AI summary of our contract. Using it would have set back our negotiations." It is a little deflating to boil careful work down to that, and it is the line they can repeat.

I do not have a perfect system for this, only this one sentence. This is the exact pattern I coach through. Link in bio if you want to talk it through.
